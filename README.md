# 世脉 · 从一缕炊烟开始

一款以建设、公共政策和制度演化为核心的浏览器文明游戏。目前版本为 **v5.3.2 可玩原型**：选择“开拓”模式从村落起步，或选择“继承”模式经营城市分布、邻国格局各异，并已有货币、税制和贵族的国家，在随机地图中建设、探索、治理和交涉。

本版新增地方不满、停工罢工、内乱与城市独立，贵族可拒绝执行命令；邻国可逐步建立新城镇，战争可确定边境、商业或领土目标，实力与外交条件合适时可以谈判兼并。邻国现在也遵守住房承载、粮食消耗、劳动力、资源生产、仓储、矿产、森林、建设成本和军队补给等基础规则，仅以较低频率更新。保留 67 种建筑、11 类实物资源、建筑搜索、宏观经济与危机、多大陆地形、有限矿藏、税制贸易和分频模拟。社会与外交采用汇总模型，战争继续自动结算，不要求战术部署。



## 开始游玩

1. 在启动页选择“新的世界”，选择“开拓”或“继承”，输入名称，可填写固定世界种子或留空随机生成。
2. 两种模式均从纪元 0 年开始，时间默认暂停。开拓模式拥有 36 位村民、7 座茅草屋和火塘；继承模式按种子生成 2–5 座城市，每城约 2,400–5,700 人；周边有 2–5 个国家，每国 1–3 座城镇。城市、人口、位置、部分设施和封地分布随种子变化；开局已有贵族、宗教组织、住房和公共设施。
3. 点击已探索的陆地空地，按需选择规模，可搜索建筑名称、用途、产出资源或英文标识，再点击建筑，即刻在该处动工。搜索仅显示当前已解锁项目。
4. 点击右下角播放。基准速度为现实 1 小时对应游戏内 1 世纪，可选 1×、5×、12×。初次体验可用 12× 观察施工和数年的变化。
5. 为新增人口补充住所和食物，通过政策积累知识、改善生产，解锁作坊、议事屋、集市等项目。城镇民居、集合住宅与农庄支撑较大城市；风车和水磨提高粮食加工效率，防御设施减轻袭扰损失。
6. 议事屋建成后，可从“制度 → 安排”分配公共劳动。城市形成后，“制度”出现货币革新；由玩家主动推行，之后才显示国库、分税种税制和货币收入。新建继承模式开局已沿用货币、基础税种、地区行政和市政章程，不需重新推行；旧档保留原来的选择。
7. 点击“探索 → 派出探索队”，再点击已知土地边缘。探索队需要时间返回，进度可从地图或探索面板查看；完成后才扩展视野并带回发现。人口达到 60 人并准备资源后，可点击已探索地区的“建立新聚落”，输入名称并确认；取消命名不消耗资源。
8. 继承模式已有多个邻国；村落发展成城市后，人口达到 600 人，可以在远离本国聚落的新探索地区接触邻国。点击已接触的邻国城市或顶部“势力”管理通商、使节、互不侵犯约定、巡防与禁运。可逐国拟定进口和出口物资与数量；货币推行后按货款结算，出口支付对方关税。关系和边界紧张会影响贸易。
9. 从“制度”切换到“财政”“文化”或已形成的“贵族”事务。财政中分别设置税率及贵族、教团豁免；文化中可对指定地区安排节庆与传统保存，观察信仰和凝聚力缓慢变化。
10. 改革前查看政治阻力和落实时间。制度改革需要逐步完成后才采用新制度，较大变革会承担更强抵制；贵族和宗教组织的态度也会影响阻力。
11. 从“势力 → 战争”组织动员，再向邻国宣战；战斗自动发生。战争持续占用劳力和补给，可提出互相停战、赔偿议和或要求补偿。停战后另行解散部队，停止平时养兵消耗。

12. 在“财政 → 经济运行与调控”或“报告 → 经济运行”查看总需求、GDP、产出缺口、失业和通胀。公共支出影响需求与国库，银行建成后可调整利率和信贷。发行公债会增加资金及债务，利息持续支付；危机重要公告可直接打开调控面板。
13. 从“仓库 → 矿产与勘探”查看已知矿区。手工作坊建成后，在已探索地区派队勘探，耗费 24 粮食、12 木材，2.5 年后返回。矿区按钮可定位地图；在矿区范围内点击空地，再搜索相应矿场即可建设。矿藏有品位与有限储量，铜可加工工具，黄金可出口。
14. 新建存档使用多大陆、海岛与气候区地图。地形影响农业与建设，同类住房在沙漠、雨林、寒冷和温带地区有不同外观。已有存档保留旧地形，不强制重新生成。

## 本稿包含

- **启动与存档**：艺术化主标题和突出的继续、新建、读取按钮，移除装饰性副标题；新建旅程、继续最近旅程、存档列表、删除确认、手动保存和每 30 秒自动保存。保存在当前浏览器的 `localStorage`，新增旅程不再自动淘汰旧存档；支持原始备份、上次备份、导入与导出。
- **双开局模式**：“开拓”从村落起步；“继承”按种子生成 2–5 座各有几千人的城市，已有货币、基础税制、贵族领地、宗教团体、城镇住房、庄园、城墙及供水等设施，周边 2–5 个有不同城镇数量与物资禀赋的国家。已有旧存档保留原地图、人口和制度选择。存档保留税制、文化、贵族、战争、国家关系、货币状态和在途探索进度。
- **邻国经济与地缘互动**：邻国按固定速率发展。玩家逐国决定进出口，货币采用前等值实物交换，之后按货币支付；缺少货物或资金时不会凭空获得输入；关系、紧张程度和禁运影响贸易。可派遣使节改善关系、签订互不侵犯约定、进行边界巡防或实施禁运。紧张升级可造成边界运输损失；地图显示外国城市、疆界与商路。
- **货币由玩家革新**：城市形成前以资源与公共劳动组织发展，不显示货币、货币税率或货币收入。城市形成后仍需玩家主动推行：消耗 24 木材、18 石材，公众信任下降 。采用后开放国库与按发展条件可征收的税种；尚未接触邻国时不会开放关税。
- **有时长的探索**：派队消耗 16 粮食、6 木材，时长随距离、地形和交通变化。早期一队，议事屋后可同时两队；完成前不揭开目标区域、不发放发现收益。可以召回，已耗用物资不退还。
- **地图与视觉**：种子生成的大陆、新大陆、海岛、海峡、平原、丘陵、盆地、沙漠、雨林与高山，以及河流和湖泊；探索迷雾；统一地图中的世界、地区、聚落三级缩放；近景可见房屋、工地、农田、弯曲道路与活动人物，远景以聚落标记呈现。地貌、土地肥力和聚落分布图层用于观察世界。
- **67 种建设**：在 v3.2 的 34 种上新增祭祀场、神殿、公共广场、剧场、印刷坊、博物馆、贵族庄园、城堡、行会会馆、驿馆、河港、集散市场、铺装道路、供水设施、排污设施、公共电车站、税务署、砖砌住宅、兵营，并新增银行、铸币所、商贸交易所、邮驿局、取土场、铁矿场、煤矿、制器工坊、织造坊、药坊和简易堆栈；本版再增加铜矿场、金矿场和铜器作坊。分别具有资源成本、设施与人口知识前置条件及独立地图外观，未开放项目不提前展示。
- **时代形态**：中世纪住房采用石墙瓦顶，工业化后原有茅屋自动更新为砖房并保留原人口容量、建筑身份及规模，不能凭更新获得新建砖房的 400 人容量。旧作坊、议事屋、粮仓、学堂等外观和道路铺装随时代调整；有轨电车、铁路与工业设施逐步开放。该更新属于建筑材料和外观的时代适配，未模拟逐栋付费重建。
- **建筑实际作用**：木栅、塔楼与城墙减轻袭扰和边界冲突损失；风车和水磨结合农田提高粮食加工效率，水磨需要靠近河流；仓库改善施工调配，农庄提供集中农业产出，密集住区增加城市承载。文化建筑保存知识并影响凝聚，贵族庄园提供农业与住房，行会协调生产，河港改善运输施工，供排水提高城市承载与稳定，税务署支持后期税制，兵营开放常备动员。风车叶片、水轮和电车有动态表现。
- **发展前置链**：解锁同时检查人口、单城规模、知识、已有设施与工业化条件。工业工场要求单座本国城市至少一万人、知识及机械作坊和仓库；全国分散人口相加不能替代单城规模。工场建成后才形成工业化，随后开放公立学校，再开放公共教育条款。学习屋、书院等早期知识设施仍可在工业化前使用。
- **组合议案**：自行命名，从 28 项逐步开放的条款中组合最多六项可用条款，选择地区、对象、执行组织、触发条件与期限；可修改、暂停和恢复。未开放内容隐藏名称、说明和门槛，可用条款显示实际代价与阻力，逐地区扩散。组合的变动幅度、收益和范围影响阻力、信任与落实速度；仅改名等无实质变化的修订不重复施加变革代价。名称输入不自动生成规则。
- **宏观经济与危机**：总需求 AD = C + I + G + NX，消费、投资、公共需求、净出口共同影响实际活动与就业；税负抑制消费和生产，财政刺激增加需求与通胀压力。供给冲击、过度信贷、需求不足与债务压力可形成四类危机，支持对应干预及持续恢复判定。物价指数影响货币建设成本和贸易单价。
- **矿产与仓储**：11 类实物资源含新增铜料与黄金；石灰岩、黏土、铁、煤、铜、金六类地质矿藏具有位置、品位与有限储量。勘探逐步揭示已探索地区的矿藏；矿场实际扣减储量，共用矿藏不会重复生成资源，满仓停采，耗尽后重要提醒。
- **渐进自动建设**：议事屋开放住房与食物委托；作坊、人口与知识达到条件后增加木材、石材和道路；研究设施提高并行量与规模。自动工程实际扣料，保留食物储备，任务可调整。
- **早期敌对势力**：村落开局约第 3 年出现附近氏族，压力可能引发袭扰，可巡防、贡粮或交涉；继承模式直接面对 2–5 个周边国家。
- **实际资源反馈**：食物供应不足导致死亡和人口下降；伐木消耗附近有限树木，地图出现空地与树桩，耗尽后产出下降。尚无自然再生系统。
- **4 类基础制度**：公共治理、产权规则、资源配置、劳动组织，共 16 个具体选项。改革前预览实际成本、政治阻力和落实时长；改革进行期间保留原制度，完成后采用新制度。变革越大、预期收益越高，通常面临更强抵制、更多信任压力和更长落实时间。
- **分阶段税制**：货币采用后，可根据议事屋、庄园、市场、邻国接触和工业化等条件开放人头税、土地税、国内贸易税、关税、增值税。每种税使用不同税基，面板展示税率、计价税基、年收入和弊端；高税负实际影响生产、贸易与公众信任。关税依据实际进口量计算，不再叠加旧版固定关税收入；无贸易就无该项税收。贵族和教团豁免会缩小应税份额，取消豁免增加收入潜力并带来政治反对。
- **公共分配**：议事屋解锁建设、生活、知识三类公共劳动安排，影响建设、稳定和知识积累。货币前只使用实物与劳役，采用后再增加国库和税务，不在村落开局提前展示货币。
- **地区宗教文化**：各聚落分别记录本土信仰、教团信仰、世俗文化比例，以及传统与凝聚力。节庆、传统保存、公共或宗教资助、宽容和限制等具体行动改变地区状态，变化需要时间。国教地位、信仰平等和工业化后的政教分立按条件开放；资助有持续资源消耗，储备不足会暂缓。文化和宗教建筑影响知识、稳定与战争支持。多样性本身不自动惩罚稳定，工业化也不会令宗教自动消失。
- **不满与地方危机**：通过“制度／报告 → 社会与地方”查看不满来源、地区生产与公共执行。持续高压可引发罢工、内乱和人口损失，严重的非首都城市危机可导致独立。救济、协商与地方自治有实际费用和期限，自治对征税与政令执行作出让步；改善食物、税负、住房与就业才能长期恢复。
- **贵族与组织利益**：继承模式已有贵族影响、支持和土地份额。可征召贵族协助、确认领地特权，或逐步推行领地权责宪章；支持、特权、免税及改革阻力实际关联。采用少量组织汇总，支持过低且影响力较强时，贵族会拒绝协助征收、征召和地方政令；改善支持并维持一段时间后恢复。仍不模拟每位贵族或居民。
- **轻量战争**：可主动宣战或受到高紧张邻国进攻；动员从地方征召起步，兵营开放常备动员，士兵逐步集结并占用生产劳力。自动战斗的胜算由知识、兵力、社会支持、补给、财政和守方防御综合影响，胜败与伤亡通过随机事件结算。战争消耗粮食、木材，货币采用后还消耗军费，并中断交战双方贸易、积累厌战；伤亡扣减实际人口。战况和时间影响和谈条件，可互相停战、支付赔偿或要求对方从现有储备中补偿，停战保护十二年。可确定边境安全、商业通行或具体城市领土目标，通过相应和平条约实现；实力和外交条件满足时也可在和平时期谈判兼并。不含战术布阵。
- **简化文明演化**：河畔营地 → 定居村落 → 农业共同体 → 早期城邑 → 地区国家 → 工业社会 → 现代文明 → 未来共同体。阶段依据人口、知识、生产力和已完成建设判断，不按固定年代自动跳转。
- **数据报告**：资源收支、人口住房与历史趋势可主动查看。阶段报告每 25 年检查显著变化后才推送，同标题与类型设冷却，减少重复。

## 当前简化范围

- 财政采用公共储备、分税种税基与预算配置模型。人头税按人口计价，土地税按农业产能估算，国内贸易税与增值税使用人口、生产和商业设施的不同汇总税基；尚无逐笔交易、地籍、完整国民账户或企业增值账簿。已加入债务、利率、通胀与危机；产出和需求为简化指数，公共需求按 2% 比例折算实际国库支出，非完整货币国民账户。需求乘数为简化估计，尚无企业资产负债表、工资、私人融资和多渠道项目融资。
- 邻国采用固定增长率、实际库存和财政储备的汇总模型；玩家可设置逐种进出口数量，货币采用后按基础价、物价指数、活动与粮食供给压力形成的单价结算，出口扣除对方关税。尚无完整邻国经济 AI、地区价格竞争、汇率、工资、产业转移或地区市场；仓储采用全国共享库存。人口变化、迁入和政策覆盖也采用汇总计算。
- 社会形态只实现四类基础制度、对应政策和少量历史标签，尚未覆盖讨论记录中的完整历史形态库。
- 时代跨度采用八个简化阶段与设施前置链，尚无完整科技树、全时代内容量和多路线阶段门槛；人口增长至万人城市的完整游玩节奏与长期平衡仍需后续验证。
- 地形影响农业产出和建设成本，矿产禀赋影响选址及产出；尚无海运、跨海殖民专门规则、复杂交通寻路或逐地区市场。矿产地图的海峡可探索，但没有独立舰队模拟。
- 大型项目具备风险新闻和随机失败，但还没有完整的筹资—分期支付—延期—债务压力模型；成功后不额外施加副作用。
- 战争使用国家层面的汇总兵力、自动战斗与有限和谈条件；没有战术部署或海陆军分类；领土转移以整座城市及其地区为单位，和平兼并以整个邻国为单位，尚无逐格占领或复杂国界条约。邻国战争意愿使用关系、紧张与停战期限的简化判断，尚非完整战略 AI。贵族和宗教团体也使用汇总影响与支持，不含完整阶级、政党或王朝政治。
- 宗教文化以三个通用分布类别和地区数值表现，尚无完整宗教名称库、教义、跨国传教、独立文化地图层或细致的战争迁徙文化传播。建筑时代更新不扣重建费用，也不模拟完整城市更新工程。人物为程序绘制的地图角色，不包含历史人物肖像或完整角色模拟。
- 存档仅保存在本浏览器；清理网站数据会移除存档。保留原存储键，可自动迁移第二稿及第三稿旧存档。尚未记录货币状态的旧存档将原有货币余额各半换为木材、石材，不自动采用货币；已有进度保留。支持 JSON 导入导出和本地备份恢复；尚无第一稿迁移或云存档。

邻国由独立的轻量国家账本结算。每个城市保留实际人口、住房、建筑资产和施工进度；国家保留库存、仓储容量、生产、消耗、财政与稳定度。人口增长受每城已完工住房承载量 105% 上限约束，粮食会被居民和军队消耗，缺粮会降低满足度、经济活动和人口；原料不足的加工设施停产，矿藏与森林沿用玩家地图上的有限储量，仓库满时产出停止并记录溢出。邻国建设会检查时代、人口、知识、前置建筑、地形与真实资源成本，项目分阶段完工，不再凭空增加设施。

邻国自动规划会按住房、粮食、木材、石材、仓储、生产链和市政缺口安排项目，并在外交页的“人口与生产”中按需查看各城承载、库存、年产出、消耗和施工进度。地图使用同一套邻国实际建筑资产；扩张建立的新城也要支付房屋、农田和基础设施成本，并从既有城市迁入人口。战争会扣除邻国补给，低供应会削弱其兵力和战斗表现。

邻国发展不再每个玩家画面帧都计算。游戏时间仍连续累计，待处理的邻国时间写入存档；设备负载以画面帧时间和上次国家结算耗时估计，将邻国账本更新间隔自动调整在 1–5 秒之间。设备繁忙时延长间隔并批量补算，性能恢复后逐渐缩短；相同外部条件下，批量大小不改变累计人口、资源、建设或战争消耗。贸易、外交、地图绘制和玩家国家系统仍按原有频率运行。

范围仍采用国家和地区汇总，未加入外国逐户家庭、企业账户、跨国物流路线、舰队或完整外国战略 AI。邻国代表设施在旧存档迁移时从已有城市状态生成；玩家接收城市时继续保留真实资产身份。
