# 世脉 · UI 视觉试稿 01

直接打开本目录的 `index.html`。这是独立视觉样稿，不加载游戏脚本、不读写游戏存档，不改变现有游戏。

可预览：
- 聚落、现代城市、大地图三种场景。
- 地区详情、建设占地、政策反馈、主要社会报告、来信及国家信息面板。
- 日光与暖光对比；地图拖动、缩放及面板收起。

本轮待评审方向：
1. 由整体暗色改为明亮自然的地图，浅色纸面信息层。
2. 地面、植被、建筑阴影、丘陵、河岸及远景氛围形成层次。
3. 保持像素颗粒，不用光滑几何模型替代地图。
4. 基础房屋加入偏置门窗、附屋、不同屋脊与局部细节。
5. 常驻信息集中上方；右侧详情只在操作后显示。

所有数字、政策效果和信件均为示意。现代建筑、地图与城市布局是画风草图，不代表真实产能、建筑密度或地形生成结果。
